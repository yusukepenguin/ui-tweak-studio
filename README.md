# UI Tweak Studio

ファイルをアップロードして、CSS変数をGUIで調整しながらリアルタイムプレビューできるブラウザツールです。  
調整結果はそのままダウンロードしてプロジェクトに反映できます。

## 使い方

1. **ファイルをアップロード** — HTML / CSS / JS をドラッグ&ドロップ
2. **変数タブを開く** — CSS変数が自動分類される（カラー・スペーシング・タイポグラフィ・角丸）
3. **GUIで調整** — カラーピッカー・スライダー・テキスト入力でリアルタイム反映
4. **ダウンロード** — 変更済みファイルをそのまま取得（複数ファイルはZIP）

## 機能

- CSS変数の自動検出・分類
- カラーピッカー / スライダー / テキスト入力
- リアルタイムプレビュー（iframe）
- モバイル / タブレット / フル幅 切り替え
- Cmd+Z / Cmd+Y でアンドゥ・リドゥ
- 変更済み変数のバッジ表示
- 変更済みコードのコピー
- 複数ファイル対応（ZIPダウンロード）

## ファイル構成

```
ui-tweak-studio/
├── index.html   # マークアップ
├── style.css    # スタイル
├── app.js       # ロジック
└── README.md
```

## GitHub Pages でのデプロイ

1. このリポジトリを GitHub にプッシュ
2. Settings → Pages → Deploy from branch → `main` / `(root)` を選択
3. 数秒で `https://<username>.github.io/ui-tweak-studio/` で公開される

外部ライブラリ依存なし（JSZipはZIPダウンロード時のみCDN読み込み）。
